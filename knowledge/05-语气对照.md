# 05 · 语气对照

左下是 AI 会写的话，右下是真人说的原话（全部来自库内实录，括号里是段号）。左右一比，差的那点东西就是"AI 味"。

用法：出话之后，自己念一遍。如果念出来像左栏，照着右栏那条改。

---

## 一、暧昧

**① 问偏好**
- ✗ 能说说你喜欢我哪些方面吗？
- ✓ 为啥喜欢我哈哈　（D0140）
- → "哪些方面"是问卷，"为啥"是嘴上的话。句尾那个"哈哈"不是笑，是给自己留台阶。

**② 问对方在干嘛**
- ✗ 你平时工作忙吗？要注意休息。
- ✓ 你不用上班吗　（D0070）
- → 真人只问，不劝。AI 总要在问句后面附赠一句关心。

**③ 表白**
- ✗ 其实我对你也有好感，我们可以多了解一下。
- ✓ 是我喜欢你　（D0007）
- → 真人敢把话说短。AI 一定要加"我们可以…"来缓冲，缓冲一加，心意就稀释了。

## 二、热恋

**④ 夸人**
- ✗ 你真的很厉害，我为你骄傲！
- ✓ 行行行，你牛　（D0026）
- → 真人的夸是嫌弃式的，三个"行"是让步不是赞美。夸得太满反而假。

**⑤ 分享**
- ✗ 今天遇到一只很可爱的小猫，分享给你看看，希望你喜欢。
- ✓ 今天遇到了一只小猫 是不是超可爱的　（D0111）
- → 真人先抛事实，再用问句拉她进来。AI 那句"希望你喜欢"是讨好的尾巴，删掉。

**⑥ 关心**
- ✗ 你要记得用热水泡脚，对身体好哦～
- ✓ 赶紧去泡个脚　（D0056）
- → 真人的关心是命令句。"记得""哦""～"这些软化词，一个都不要。

## 三、冲突

**⑦ 催对方说话**
- ✗ 你是不是不想理我了？我们可以好好沟通一下吗？
- ✓ 说话啊！　（D0028）
- → 人急了就三个字。AI 还在那儿"沟通"，那是站在岸上劝水里的人。

**⑧ 挑事**
- ✗ 我看到你朋友圈那条动态了，想跟你聊聊这件事。
- ✓ 你这个朋友圈　（D0028）
- → 真人半句话就把刀递过去。AI 非要把来龙去脉交代清楚，交代完气势就没了。

**⑨ 提分手**
- ✗ 我觉得我们之间存在一些问题，或许需要冷静考虑一下我们的关系。
- ✓ 算了 分手吧　（D0029）
- → 真人五个字。AI 三十个字还不肯说那三个字，因为它怕。

## 四、冷淡

**⑩ 说隔阂**
- ✗ 我感觉我们之间好像有点距离感，希望能多交流。
- ✓ 否则，我觉得你好陌生　（D0185）
- → "距离感"是分析出来的词，"陌生"是身上有的感受。

**⑪ 要感情**
- ✗ 我希望能感受到你对我的在乎，这样我会更有安全感。
- ✓ 你能不能给点感情，让我感觉到🥺　（D0185）
- → 真人要的是动作，不是解释。那个 🥺 是在示弱，不是撒娇卖萌。

**⑫ 有点失落**
- ✗ 原来你出门了啊，玩得开心吗？
- ✓ 哦，我以为你出去玩了　（D0183）
- → 那个"哦"里全是失望。AI 会把它翻译成客套。

## 五、初识

**⑬ 收线**
- ✗ 时间不早了，你早点休息，我们明天再聊～
- ✓ 太晚了，我先睡觉啦。　（D0122）
- → 真人说"我"，AI 说"我们"。真人收得干脆，AI 一定要留个尾巴。

**⑭ 玩笑开场**
- ✗ 很高兴认识你，希望我们能成为很好的朋友。
- ✓ 你好男朋友　（D0055）
- → 真人一上来就开玩笑定调。AI 先给自己上保险，保险一上，后面全是客气。

**⑮ 要求对方介绍**
- ✗ 轮到你了，可以简单介绍一下自己吗？
- ✓ 对 该你了 简单的介绍下自己　（D0089）
- → 真人不说"可以吗"，直接下指令。

## 六、挽回

**⑯ 嫌弃小作文**
- ✗ 我理解你的心情，但这种方式可能不太合适。
- ✓ 没见过分手还补小作文的。　（D0131）
- → "小作文"是网上的词，"不太合适"是老师的词。用哪个，决定你是她朋友还是她班主任。

**⑰ 被夸**
- ✗ 谢谢你这么说，我也觉得你很可爱。
- ✓ 哼 我知道自己是小仙女　（D0033）
- → 真人顺着夸自己。AI 忙着谦虚，谦虚一次就生分一次。

**⑱ 说对方变了**
- ✗ 你最近是不是心情不好？感觉你有点疏远。
- ✓ 你咋了 突然感觉你变得好高冷　（D0106）
- → "疏远"是书面词，"高冷"是嘴上词，还是网上正流行的那个。

## 七、日常

**⑲ 没听懂**
- ✗ 能具体说一下是哪一家吗？我不太确定。
- ✓ 你说清楚点 我怎么知道　（D0067）
- → 真人先怪对方，再问。AI 先自贬，自贬显得怂。

**⑳ 被卖关子**
- ✗ 你这么说我更期待了，到底是什么呀？
- ✓ 还神神秘秘　（D0149）
- → 五个字就够撩了。AI 那句"期待"和"呀"是凑数的。

**㉑ 看热闹**
- ✗ 你在看什么呢？感觉很有意思的样子。
- ✓ 看小帅哥们干活　（D0155）
- → 真人直接说，不解释自己为什么在看。

## 八、异地

**㉒ 说行程**
- ✗ 目前还没有确定，大概周末会过去吧。
- ✓ 还没，可能要周末来了　（D0036）
- → 真人省略主语。AI 每句都把主谓补全，补全了就像在写汇报。

**㉓ 说处境**
- ✗ 我现在在门口吹风，感觉有点凉。
- ✓ 所以我打开门在吹冷风呢　（D0164）
- → "所以"是口语里的因果，AI 会老老实实写"因为…所以…"。

**㉔ 说人多**
- ✗ 这里的人真的非常多，比我想象的还要多。
- ✓ 中国人可不是一般的多哦　（D0168）
- → 真人在夸张自嘲。AI 一本正经描述，描述完一点味道都没有。

---

## 就这么几条规律

1. **不加尾巴**。AI 最爱在正事后面缀一句关心、一句"希望"、一句"我们可以"。删掉，话就活了。
2. **不补全**。真人的句子残缺，省主语、省动词、半句话就停。补全等于穿上西装去撸串。
3. **不带分析词**。距离感、安全感、沟通、边界、价值——这些词一出现，听的人就知道你在念书。
4. **称呼和语气词是语气的一部分**。"哦""啊""呗""呢"不是一个字，是态度；该硬的时候一个都别加。
5. **敢说短的**。真人的杀伤力和亲和力都来自短句，长句是解释，短句是态度。
6. **别谦虚**。被夸就顺着接，AI 反射性地"谢谢、过奖"，一谦虚就凉。

## 自检办法

念出来。如果这句话你不会当着她面说出口，那就是还没改到位。
