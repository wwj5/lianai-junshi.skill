# 阶段与卡点

## 九档定义

| 阶段 | 一句话判断 | 典型内容 |
|---|---|---|
| 初识 | 刚加上、刚认识，还在互相试探 | 开场、破冰、第一次接话 |
| 暧昧 | 有来有回，但没挑明、没单独见过 | 拉扯、专属梗、试探邀约 |
| 热恋 | 已确立关系 | 日常腻歪、报备、撒娇 |
| 冲突 | 吵架、冷战、质问 | 解释、道歉、哄、翻旧账 |
| 冷淡 | 单向投入，她在退 | 已读不回、敷衍、"嗯""哦" |
| 异地 | 距离/时差导致的相处形态 | 通话、报备、倒计时、见面计划 |
| 挽回 | 分手后、断联后重新接触 | 冷激活、第一条重启消息 |
| 谈婚论嫁 | 见家长、彩礼、结婚安排 | 双方父母、钱、房子、日子 |
| 日常（兜底） | 没有任何阶段标记的普通对话 | 废话、段子、吃喝 |

## 分手后·仍保持联系（挽回档的子情形）

关系已经结束，但两个人还在正常说话。这时候最要紧的不是话术，是**他要的到底是哪一件**——三种目标的话完全不一样：

| 目标 | 判据 | 这一轮只做 |
|---|---|---|
| 复合 | 双方都还有没清的情绪，或她主动提过过去 | 先恢复"能正常说话"，不谈关系 |
| 维持（做朋友） | 她回复正常，但没有旧称呼、不主动开私人话题 | 守住朋友分寸，不越线 |
| 收线 | 他其实想放下，只是舍不得断 | 干净地结束，不拖 |

**三个最常见的误判：**

1. **"她还愿意回我" ≠ "还有机会"。** 她回你，多半是因为不恨你，不是因为想回来。分手后的朋友聊天，友好是默认状态，不是升温信号——这一条必须在分析里明说，不能顺着他往下想。
2. **拿旧身份的亲密当探针。** 叫昵称、问"今天怎么又熬夜"、查行程、翻旧账——她现在的位置是朋友，这些在朋友之间叫越界，她会立刻缩回去。
3. **"我改了""我们谈谈"开场。** 这是挽回话术，用在已经放下的人身上就是压力，她要么敷衍，要么直接不接。

**分手后朋友聊天的五个降温信号（比表情、秒回都准）：**

- 只回不问，连续三轮没给出新信息
- 只在有事时回（取快递、问路、借钱）
- 句子变完整、表情变少、语气变正式
- **不接你的玩笑**（这条最准，还能开玩笑说明没设防）
- 深夜不再回，白天回得很快

出现两个以上，按"维持"档走，频率降到她回你的频率以下。

**三条各自的第一句长什么样：**

- 复合：先用一件跟过去无关的正经事，把"能正常说话"这件事恢复起来，别用"最近怎么样"这种空开场
- 维持：用共享的旧接口（共同的群、共同的朋友、她以前提过的事），一次一件，不追问
- 收线：一句话说清，不解释、不辩论、不留台阶给她反驳，然后真的停

**不许做：** 吃醋、打听她新认识的人、把"做朋友"当缓兵计、托共同朋友传话、翻她社交账号找线索。

## 升级条件：只有这些才算

| 从 → 到 | 唯一凭据 |
|---|---|
| 初识 → 暧昧 | 事务之外，她**自愿**开启并延续个人话题；会反问你的经历 |
| 暧昧 → 热恋 | 双方明确表达好感，且愿意/已经单独见面 |
| 热恋 → 谈婚论嫁 | 双方开始谈见家长、住处、钱、日子这类现实安排 |
| 任意 → 冲突 | 出现明确的对抗、指责、冷战 |
| 任意 → 冷淡 | 连续多轮单向投入，她持续不给新信息 |
| 任意 → 挽回 | 关系已断（分手/拉黑/长期断联）后重新接触 |

## 明确不算信号的十种情况

1. 认真回复、说"谢谢""哈哈"、用表情 —— 只说明她礼貌
2. 求你帮忙、问课程、问工作 —— 事务互动
3. 顺路碰面、因为项目/同事/同学见过 —— 场景巧合
4. 群体局里聊得好 —— 有第三人在场，防御低是正常的
5. 回得快 —— 可能只是她正在玩手机
6. 深夜聊过一次 —— 夜里人松懈，不代表白天也这样
7. 她主动发过一次消息 —— 单次不算，要看是不是持续
8. "哥""宝""亲爱的"这类称呼 —— 有人对谁都这么叫
9. 给你点赞、看你朋友圈 —— 最低成本动作
10. 答应邀约但没定时间 —— 客套性答应，仍算原阶段

## 关系卡点表：先找卡点，再选技巧

| 阶段 | 常见卡点 | 优先动作 |
|---|---|---|
| 还没建立联系 | 开场没有共同点、资料空白 | 现场取材、从她的动态找具体切口 |
| 初识聊不动 | 连环审问、只聊自己、话题跳 | 接—放—给—抛 |
| 聊得顺但没张力 | 只有信息交换，兴趣始终含糊 | 具体欣赏、轻松调侃 |
| 暧昧但不落地 | 长期网聊，双方都不提行动 | 低压力邀约、时间窗口 |
| 推进后反复冷却 | 互惠不足或节奏太快 | 降级投入、澄清、设停止条件 |
| 关系内常吵架 | 情绪没接住、需求没说清 | 倾听、协商、修复，不用调情跳过 |
| 冷淡期 | 越追越退 | 降压、收线、给空间 |

## 红黄绿灯

| 灯 | 可观察表现 | 怎么做 |
|---|---|---|
| 绿 | 主动延展、反问、开玩笑、给新时间、主动换话题 | **只升一小级**，再观察 |
| 黄 | 礼貌但很短、连续不反问、说忙说累、对打趣只勉强回应 | 降张力，换轻话题，或结束这一轮 |
| 红 | 明确拒绝、表达不适、停止回应、要求别联系 | **立即停**，不辩论、不测试、不追问 |

单个表情、一次秒回、聊到深夜，都不是承诺证据。看趋势、现实投入、边界反应。
