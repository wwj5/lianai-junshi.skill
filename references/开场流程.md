# 开场流程

给 AI 用的一套固定开场。谁都是第一次说话，都从同一句骨架起步。之后只看对方回复的**形态**分流，三轮封顶，不接就停。

这套东西解决的是「第一句怎么起」和「她回了之后我往哪走」。它不解决「她喜不喜欢你」，那不是一句话能解决的。

---

## 一 骨架 三个槽

一句话 = 三个槽，顺序固定，缺退路最容易出问题。

| 槽 | 放什么 | 具体要求 |
|---|---|---|
| 由头 | 你们之间真实存在的连接 | 同一个群 / 同一场活动 / 有人介绍 / 工作对接过。**必须真** |
| 身份 | 一个能让人定位你的标签 | 姓 + 一个特征，或岗位。不用全名，不用职务全称 |
| 退路 | 把选择权交回去 | 「有事你说」「有事喊我」。让她可以安全地只回一个字 |

三条硬规矩：

1. **不用问句开场。** 第一句是问句，她会默认你在审问，回一个最短的答案就跑。
2. **不夸。** 第一句夸人，后面每句都得靠夸撑着，撑两句就油。
3. **不解释为什么加。** 解释越多越像有事。

骨架长这样：

```text
[由头] [身份] [退路]
```

---

## 二 四种由头 同一句骨架

句子只换第一个槽，后面两个槽不动。

| 由头 | 一句现成的 |
|---|---|
| 同一个群 | 群里看到你 姓吴 潜水那个 有事你说 |
| 同一场活动 | 那天后排那个 姓吴 有事你说 |
| 有人介绍 | 老 L 给的号 姓吴 有事你说 |
| 工作见过 | 上次对接那个 姓吴 有事你说 |

骨架一样，但这句话强不强，不在句子本身，**在由头真不真**。

由头真，第二句她就有得接。由头假，后面每句都在补窟窿，补到第三句一定露。

## 三 分流 只看形态

她回什么，先归到四类里。**只归一类**，按顺序判，先命中先用。判的是形态，不是意思。

| 顺位 | 出现这些 | 归类 |
|---|---|---|
| 1 | 有问号，或 你谁 / 哪位 / 干啥 / 怎么加的我 | A 反问 |
| 2 | 我是 / 我叫 / 我在 / 我做 / 我们 | C 自述 |
| 3 | 哈哈 / 嘿嘿 / 表情包 / 两个以上语气词（啊 呀 呢 吧 哦 嘛 哈） | D 情绪 |
| 4 | 其余，尤其三个字以内、没问号、没语气词 | B 短闭 |

两个特例：

- 既带问号又带情绪 → 判 **A**。问号优先，因为她在要信息，不在玩。
- 只有一个语气词（「嗯」「哦」）→ 判 **B**。一个语气词不是热情，是礼貌性的最小回复。

## 四 每条路 下一句给什么

### A 补身份

结构：`标签 + 一件具体事`，不提问。

```text
潜水那个 姓吴 天天不说话
```

- 一件事要具体到能想象出画面（潜水、后排、只发图片不说话）
- 不连发两条自我介绍
- 不补「我这人挺好」这类自我评价

### C 同层交换

结构：`我这边的具体一件事 + 你那边呢`（后半句可省）。

```text
我这边天天守着设备 你那边忙啥
```

- 先给，再问。给的东西必须是她能用的信息，不是情绪
- 她自述了职业/位置，你就往那个方向上给一条你真实的经验
- 不追问细节。她是质检，就别问"你们几班倒"

### D 顺梗

结构：`接住她的点 + 留一句`。

```text
你这笑点低 我记下了
```

- 顺完不邀。第一轮不提见面
- 不把梗无限延展。接一句，把球留给她

### B 短闭

**不发。**

等一天。换一个由头（只换由头，身份不动），只换一次。第二次还是短闭 → 停。

短闭不是拒绝，但也绝不是邀请。这时候追加，等于把「我在等」写在脸上。

## 五 三轮封顶 与 门

| 轮 | 干什么 | 一句话 |
|---|---|---|
| 第 1 轮 | 开场 | 骨架那句 |
| 第 2 轮 | 分流 | A / C / D 三选一 |
| 第 3 轮 | 给门 | 一个具体、可兑现的东西 |

门 = 一个具体、可兑现、**不需要她现在答应**的东西。按轻重排：

| 门的类型 | 例子 | 适用 |
|---|---|---|
| 最轻 一句承诺 | 有事喊我 | 任何情况 |
| 有物 | 那个资料我发你 | 聊到过具体内容 |
| 有时点 | 下次有这类我提醒你 | 她的工作/兴趣有周期性 |

门之后**不加第四轮**。她接门，就落一次具体（时间或物件）；她不接，就停。

---

## 六 停的三条硬线

1. 连续两次 B 类回复
2. 任何一次拒绝，包括敷衍式拒绝：「不用了」「算了」「再说吧」
3. 门给了 24 小时没接

停 = 不再发。不是删人，不是发一段质问，不是「打扰了」。

## 七 判定样例 脱敏

| 她回的 | 判 | 你下一句 |
|---|---|---|
| 哪位呀 | A | 潜水那个 姓吴 天天不说话 |
| 我叫小 Y 你也是 A 组的？ | A（问号优先） | 对 A 组 姓吴 后排那个 |
| 我是做质检的 | C | 质检那块我熟 上周那批就是我送的 |
| 哈哈 你这名字挺逗 | D | 逗就记住 别到时候想不起来 |
| 嗯 | B | 不发 隔天换由头 |
| 哦 好 | B | 不发 |
| 不用了吧 | 停 | 不发 |

---

## 八 一句话

一样的骨架 换真的由头 看形态分流 三轮给一个门 不接就停。
