# 口吻：怎么说话才不像 AI

## 我们自己的实测数据（208 段真人私聊 / 1897 轮）

句子形态：短句 102、碎片连发 51、中长句 38、长段 5
标点风格：半标点 62、空格断句 53、无标点 45、问号多 18、全标点 15、省略号多 3
倒装是少数派，别故意倒装

结论很直白：**真人打字是碎的，标点是不全的。**

## 标点：默认少打（硬规则，不是风格建议）

用户明确要求回复里不要堆标点。以下七条按顺序执行，违反任何一条都算不合格：

1. **句号一个都不打。** 末尾不打，中间也不打，写完直接断，不补句号。
2. **逗号改成空格。** 该喘气的地方打空格，不打逗号。一条消息里出现逗号就算不合格，要断就拆成两条发。
3. **问号只打一个。** 不写"？？""？！""？?"，不连问。
4. **省略号只用"…"。** 不用"……"，一条最多一处。
5. **不打包号、书名号、引号、破折号。** 要引用谁的话就直接说，不加符号框。
6. **超过 25 字先拆条。** 拆成两条比加标点更像人。
7. **表情跟着对方。** 对方没用你也别用，一条最多一个。

依据是数据本身：208 段里空格断句 53 段、无标点 45 段，合计 98 段占 47%，这一档全是句号一个不打、靠空格和换行断句；半标点 62 段也多是带问句的追问，不是每句一个逗号。全标点只有 15 段，基本都出现在冲突摊牌或表白那种"认真说话"的场合——日常闲聊照着写，一眼就是写作文。

**空格断句是库内最高频、也最好复制的形态，接口只有一句话：把想打逗号的地方换成空格。**

其余四条：

- 一句话拆两三个短句连着发，比一个长句带逗号更像人
- 允许用空格断句，允许一条消息只有两三个字
- 允许有错别字（"以经""在吗"这类），不要为了规范去修
- 长段（一次发一大坨）是少数派，只在情绪顶到头或写小作文时出现

## 六个硬动作

1. **拆短**：一句话超过 25 字，考虑断成两条发
2. **结论先行**：先给判断，再给理由，别反过来
3. **敢下判断**：判断类的话直接说（"她这就是不想见你"），不堆"可能/也许/大概/建议你可以考虑"
4. **留口头禅**：用户自己说"哈哈""草""就那样吧"，就保留，不要换成"确实如此"
5. **emoji 跟着对方走**：她不用，你也别用；她用 😂，你别上 🌹
6. **情绪浓时用平语气**：越感动越轻描淡写，越生气越冷静，"我很想你"不用写成"我真的很想你很想你"

## 黑名单

**词**：此外、至关重要、深入探讨、值得注意的是、总而言之、不仅仅是…更是…、赋能、闭环、维度、底层逻辑
**句**：
- "我理解你的感受" —— 最假的一句，换成具体的事："换我我也烦，这事儿确实恶心"
- "希望这对你有帮助""如果你有任何问题" —— 客服尾巴
- "首先…其次…最后" —— 汇报体
- "总的来说，你们现在处于…" —— 报告体
**格式**：
- 小标题堆叠（"局势判断 / 信号解读 / 行动方案"）
- 三段式排比
- 粗体滥用
- 用破折号串长句

## 消息长度的经验值

- 回她一句短消息：15-30 字，一到两条
- 回她一段倾诉：30-60 字，先接情绪再给一句自己的
- 邀约：20-40 字，必须含具体由头
- 道歉：30-50 字，认错 + 具体改法，不写小作文
- 表白：不超过 80 字，超过就像在念稿

## 怎么检索我们的库

库位置：`聊天实录素材\新增素材.jsonl`（200 段，其中 198 段可检索）
真实字段：id / source / stage / stage_method / stage_score / turn_count / turns / result / tags / note / style / roles / roles_conf
- `turns`：["说话人","原话"] 的数组
- `tags`：字符串列表，形如 `["阶段:异地","女性格:傲娇","相识:相亲"]`
- `style`：{msg_count, len_avg, len_max, pattern, punct, inverted}
- `roles`：说话人映射，形如 `{"男":"他","女":"我"}` —— **必看**。库里有三套标签（他/我、她/我、A/B），不读 roles 会把男女看反
- `roles_conf`：`ok` 表示性别已核过，`excluded` 是不该用的（第三方在聊别人的感情）

直接用脚本捞，不要手工翻：

```powershell
python scripts\取料.py --list
python scripts\取料.py --stage 冲突 --tag 女性格:戏多 --n 3
python scripts\取料.py --stage 暧昧 --style 碎片连发 --n 3
python scripts\取料.py --stage 挽回 --n 3 --brief   # 只要对话，不带标注
```

（在 skill 目录下执行；换目录就写全路径 `<skill目录>\scripts\取料.py`）

脚本会自己过滤掉 `excluded`、把标签统一成"男方/女方"输出，并按匹配度排序。

检索顺序（按库里的实际覆盖率排，别按理想顺序）：

1. **stage** —— 100% 有，这是唯一稳的维度
2. **style.pattern 和 style.punct** —— 100% 有，这一步决定"像不像她打字"（碎片连发 + 无标点 = 高频快聊；中长句 + 全标点 = 认真说话，通常在冲突或表白）
3. **女性格 / 男性格** —— 只有 43% 的段有标。**当可选加分项用，不当硬条件**：有就用它排序，没有的段照样能捞（脚本会自动降级），不然会漏掉六成库
4. **相识 / 年龄层** —— 相识 15%、年龄层 43%，基本只能碰运气，能对上才参考（学生不聊加班、相亲不讲段子）

性格怎么用来挑：她傲娇 → 找顺毛的段；她敏感 → 找给确定性的段；他心动怂 → 找磨叽但真诚的段。但先看阶段和句式，性格是最后一层微调。

**用法**：看真人这个阶段怎么接，然后按当前对话重写。
**禁止**：把库里的句子原样发给另一个人。那是别人的私聊。

## 判断"像不像"的一个土办法

写完之后问：这句话我会在微信里打出来吗？
- 会 → 留着
- 不会，但会在文章里写 → 删掉重写
- 说出口有点肉麻 → 大概率太油，减一半

## 关于确定性

AI 爱加对冲词，真人很少。判断类的句子去掉"可能""或许"会更像人。
但**事实不确定的时候仍然要说不确定**——"她是不是在忙我不知道，但连着一周都这样，就不是忙的事了"，这比装确定更可信。
