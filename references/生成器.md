# 生成器：从一句回复到后续分支

一句话不是"想出来的"，是**拼出来的**：定目标 → 配三层 → 校口吻 → 留分支。

## 一、只定一个本轮目标

七种策略选一个，最多加一个很轻的辅助动作。

### 承接
用在她在倾诉、受挫、兴奋、分享的时候。
只做一件事：让她感到内容被听见。以情感层为主。

- 只追问："忙什么？为什么忙？几点下班？" ← 审问，AI 通病
- 只表演："我今天更忙，我遇到了……" ← 自恋
- 正解："听起来你今天被工作榨干了。先给你五分钟吐槽资格，最离谱的是哪一件？"

### 降压
她忙、累、冷、回避，或者你刚追问太多。
停止追加，留一个无压力的窗口。不要发"你是不是不想理我"。

- "你先忙，我这边也有事。晚点有精神了再聊。"
关键在于**说完就真的不再发**。

### 调侃
她接梗、反问、斗嘴、主动延展。
加一点张力，然后把球抛回去。必须留她可接的出口。

- 她："你是不是对谁都这么会说"
- "这句可不是批发价。你刚说的那个 [具体细节]，值得单独回一句。"

### 轻推
聊得顺但一直在原地打转。
往前挪一小步，但不要承诺、不要表白、不要突然深情。

- 从事情转到感受："你从小就这样？" / "你最喜欢的时刻是哪种"
- 从事实转到价值观："你选这个是因为什么"

### 约见
有共同兴趣、有时间窗口、或者她已经接住过一次软邀约。
落到具体、低压力。

- 用她说过的事当钩子："上次你说想看展，正好有个摄影展挺对你口味，就我们俩去逛逛？"
- 给一个更容易接受的版本："最近发现一家咖啡馆，选品有意思，你大概会喜欢，哪天有空？"

避免："最近有空吗，出来聚聚" ——她回一句"最近挺忙"就没下文了。

### 澄清
信息矛盾、期待不明，或者有一个未知会直接改变判断。
一次只问一个关键事实，问完就用，不要连带问三个。

### 收线
持续单边投入、反复取消、明确拒绝、边界不合。
停止无效供给。不是拉黑，是不再主动。

## 二、按需配三层

不硬凑。缺层是正常的，硬凑才假。

- **逻辑层**：事实、时间、地点、选项、边界 → 邀约、澄清主要靠它
- **情绪层**：幽默、调侃、画面、悬念、语气、轻微反转 → 调侃主要靠它
- **情感层**：理解、欣赏、牵挂、真实感受 → 承接、修复主要靠它

## 三、接—放—给—抛

一轮好对话四步，不必全用：

1. **接**：回应她真正在说的事或情绪
2. **放**：把有趣的细节放大一点，加画面或情绪
3. **给**：补一点自己的经历、偏好、态度，让交流变成双向
4. **抛**：留一个她方便回来的点

这条是治"不像人"的核心。AI 的两种病：
- **只追问**：一条消息里三个问号，像查户口
- **只表演**：借她的话头讲自己，讲了五句没一句关于她

真人聊天是**接一下就放，放完顺手给点自己**："这也太离谱了，我上次遇到个更绝的……"

## 四、五项口吻校准

写完之后过一遍：

1. **长度**：她一句，默认不回小作文。她三段，你可以两段。
2. **熟悉度**：初识不用"宝""乖"，伴侣不用装客气（"您好""麻烦您"在情侣之间很怪）。
3. **用词**：保留用户自己平时的"哈哈"、语气词、口头禅；删掉他不会说的油腻词（"小仙女""宝贝儿""乖"）。
4. **媒介**：文字要短，可以有错别字；语音可以有停顿和故事；线下更依赖现场。
5. **关系结构**：按具体关系来，不按性别预设谁该主动。

## 五、三档改写（同一个意思三种写法）

用户想比较风格时，给三档，并说明代价：

- **稳健**：清楚、不油、留余地
- **会撩**：加一点张力，但要留可接的出口
- **强势**：清晰、不讨好、快速筛选

强势 = 边界明确，**不是**羞辱、威胁、冷暴力。
例（她软拒绝"最近有点忙，下次吧"）：
- 稳健："好，你先忙。时间定了告诉我。"
- 会撩："行，这次先放你去忙。下次带着时间来约我。"
- 强势："可以。我不反复问了，你想见的时候给我一个具体时间。"

## 六、给台阶

邀约和开口最容易卡在"她答应了但没动"。
给她一个能说服自己的理由，不是骗她。

- 热水器式：不说"来我家"，说"我家没烧水的，你能带个热水器吗"
- 红包式：直接给钱她不要，备注"请你吃饭"她就收了
- 书包式：搭讪扯个"给我弟买的"，对方知道你在扯但配合，因为有台阶

**界限**：台阶不能盖住真实意图。想认真发展就说认真发展，别用一个假由头把人骗出来。

## 七、分数不是必须的

不要给关系打分，不要给对方的"可得性"打分。打分会让判断变成假精确。
要说就说明确的一句：现在能推，还是不能推。
